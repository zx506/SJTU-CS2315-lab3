## 3. 任务一：基于线性回归模型的反向传播

标量线性回归模型为 `pred = w*x + b`，损失为 `loss = (pred-y)**2`。

平方误差对参数的梯度为：

```text
error = pred - y
dw = 2 * error * x
db = 2 * error
```

因此，参数的更新规则是
```text
new_w = w - lr * dw
new_b = b - lr * db
```

在 `todo.py`中的`scalar_step` 函数内实现以上计算，返回 `(loss, dw, db, new_w, new_b)`。这一任务不需要使用numpy。

测试正确性：在`src`目录中运行以下命令：

```sh
python check.py --part scalar
```

代码中默认取 `lr=0.05`，第一次更新后应得到 `w=1.6, b=0.3`。

### 4.2 全连接层

设输入 `X` 的形状为 `[B,I]`，权重 `W` 为 `[I,O]`，偏置 `b` 为 `[O]`。B 是样本数，I/O 是输入/输出维度。

```text
前向：Y = X @ W + b                 Y: [B,O]
```

在 `todo.py`中实现`linear_forward` 函数。每一行都使用同一组权重和偏置，batch 大小不会改变模型参数数量。

反向传播会收到上游梯度 `G = ∂L/∂Y`，形状为 `[B,O]`。它表示损失对本层每个输出数值的敏感程度。

```text
dX = G @ W.T                       [B,I]
dW = X.T @ G                       [I,O]
db = G.sum(axis=0)                 [O]
```

在 `todo.py`中实现`linear_backward` 函数。按顺序返回 `(dX,dW,db)`。**这里不要再除以 B**，损失层会统一处理平均损失的梯度。


### 5.2 Softmax 与交叉熵

网络最后输出 `[B,10]` 的原始分数 `logits`。每行对应一张图，每列对应数字 0–9。标签 `labels` 是 `[B]` 的整数数组。

Softmax 把每行的分数变成概率。对真实类别取负对数，再对整个 batch 求平均，即交叉熵损失。

为避免指数溢出，先减掉每行最大值。为避免非常小的概率变成 0 后再求对数，直接计算 log-probability：

```text
S = logits - 每行最大值                         [B,10]
E = exp(S)                                    [B,10]
Z = 每行 E 的和，保留维度                      [B,1]
P = E / Z                                    [B,10]
logP = S - log(Z)                            [B,10]
L = -mean(logP[每行的真实类别])                标量
```

交叉熵对 logits 的梯度为：

```text
dlogits = (P - one_hot(labels)) / B
```

提示：你可以复制 P，在每行真实类别的位置减 1，再除以 B，无须构造 one-hot 矩阵。`np.arange(B)` 能生成所有行号。

填写 `softmax_ce`，返回 `(Python 浮点数 loss, dlogits)`。不要修改传入的 logits 或 labels。

检查代码：

```sh

```

检查不仅比较普通输入，还会给出很大的正负分数。损失和梯度应保持有限值。

## 6. 任务四：完整的神经网络

我们使用以下结构的神经网络：

| 步骤 | 计算 | 输出形状 |
|---|---|---|
| 输入层（展平与归一化） | 28×28 灰度图片展平成 784 个数，除以 255 | `[B,784]` |
| 全连接 1 | `z1 = X @ W1 + b1` | `[B,32]` |
| ReLU 1 | `h1 = relu(z1)` | `[B,32]` |
| 全连接 2 | `z2 = h1 @ W2 + b2` | `[B,16]` |
| ReLU 2 | `h2 = relu(z2)` | `[B,16]` |
| 全连接 3 | `logits = h2 @ W3 + b3` | `[B,10]` |

输入层与参数初始化已经提供。参数共有 **25,818 个**，请用每层的权重数与偏置数验证。

填写剩下 3 个函数：

1. `forward`：依次调用各层，返回 `logits` 和缓存 `(X,z1,h1,z2,h2)`。缓存用于反向计算。
2. `backward`：从 `dlogits` 开始，按 FC3、ReLU2、FC2、ReLU1、FC1 的顺序计算。返回键为 `W1,b1,W2,b2,W3,b3` 的梯度字典。每个梯度的形状都与对应参数一致。
3. `sgd_update`：对每个参数执行 `参数 -= lr * 梯度`。在整个网络完成反向传播以后再更新。

## 7. 任务五：训练，验证与推理

### 7.1 基线

## 9. 部分FAQ

| 现象 | 优先检查 |
|---|---|
| 矩阵形状不匹配 | 写出 X、W、G 的形状，检查转置 |
| db 形状不对 | 是否沿 `axis=0` 汇总 |
| 梯度比参考小很多 | 是否在每层都重复除以 B |
| CE 出现 inf/NaN | 是否减行最大值，是否直接取了 `log(0)` |
| 小样本校准测试不过 | 层顺序、ReLU 掩码、梯度方向、更新顺序 |
| 每类都输出相似分数 | 权重是否全为 0，梯度是否没有传回前层 |
| 验证结果比最后一轮好 | 正常现象，比较 best 与 last，不要求准确率单调上升 |
